Print Machine spike

Print Machine is about to save prints at a photo's own pixels, 40 megapixels and more, without the 16.7 MP ceiling it has today. A few things only a real phone can answer first. This page measures them. Nothing leaves your phone: the page makes no network requests.

When it finishes, tap Copy results and paste the table into the chat. It takes about a minute. A test may make the tab reload if the phone runs out of memory; that is a result too, and the page will say so when it reloads.

    What each number means

    Decode: the time the browser takes to turn the whole photo file into pixels in memory, as Save will (4 bytes a pixel: 159 MB for 40 MP). "ok" means it worked; a failure is copied word for word. A page cannot see its own memory: if you can, read the peak in Safari's Web Inspector (Timelines, Memory) on a Mac.

    Blit: whether drawing the decoded photo at its own size into a 4096 × 1024 canvas at two different row offsets gives identical bytes on the 247 rows the two share. Saving in bands needs "identical" with smoothing off.

    Crop: whether asking the browser to decode only part of an EXIF-rotated photo returns the part asked for. It decides whether a lighter-memory fallback is usable for portrait photos. The app does not use it today.

    Font: the largest canvas font size this browser honours. Print Machine needs 9216 px for very large type on very large prints.

    Canvas: whether canvases of these sizes really hold pixels. iOS hands back a blank canvas instead of an error when a canvas is too large.

    Compressor: whether this browser's built-in compressor has finished reading a piece of data by the time it says it has taken it. The lossless PNG save reuses its buffers on that promise; "exact" means every round trip came back unchanged after the buffer was overwritten.

    Speed: how fast this phone runs Print Machine's JPEG encoder, in milliseconds per megapixel, and R, that figure divided by 126 (the developer machine's). A 40 MP save is estimated at about 33 s × R; that is a rough estimate, not a measurement of a save.
